# Executive Project Summary

## Project Title
Bank Customer Churn Prediction and Risk Scoring

## Business Problem
Banks face challenges in retaining existing customers.
Identifying customers who may leave can help institutions
plan proactive retention strategies.

## Analytical Approach

1. Data exploration
2. Data cleaning
3. Feature engineering
4. Data preprocessing
5. Machine learning
6. Model evaluation
7. Customer risk scoring
8. Financial scenario analysis

## Dataset

- Records: 10,000
- Churned customers: 2,037
- Retained customers: 7,963
- Churn rate: 20.37%

## Champion Model

Gradient Boosting

ROC-AUC: 86.59%

Accuracy: 86.75%

Precision: 77.10%

Recall: 49.63%

F1 Score: 60.39%

## Business Applications

- Customer retention planning
- Risk-based customer prioritization
- Targeted customer engagement
- Financial scenario analysis

## Conclusion

The project demonstrates how machine learning can support
customer churn prediction and structured retention planning
through probability-based risk scoring.
